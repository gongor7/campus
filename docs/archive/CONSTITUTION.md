# Constitution — Campus ASFI Inteligente

1. El stack base será Vue para frontend, NestJS para backend y PostgreSQL para persistencia.
2. La lógica de negocio deberá permanecer en el backend y no depender de la interfaz.
3. El código deberá mantenerse modular, legible y con responsabilidades claramente separadas.
4. Todo requisito funcional deberá contar con pruebas automatizadas cuando sea técnicamente aplicable.
5. Los tests deberán ejecutarse antes de considerar una tarea como terminada.
6. No se incorporarán dependencias externas innecesarias para resolver funcionalidades del MVP.
7. El MVP no dependerá de un LLM, API de IA ni servicio externo de inteligencia artificial.
8. La arquitectura deberá permitir incorporar IA posteriormente sin reescribir el núcleo del sistema.
9. No se implementará funcionalidad que no esté respaldada por la spec aprobada.
10. Los cambios de requisitos deberán reflejarse primero en la spec antes de modificar código.
11. Las tareas de implementación deberán ser pequeñas, verificables y ejecutables en menos de 30 minutos.
12. Cada implementación deberá corresponder a una tarea específica del plan aprobado.
13. No se considerará terminada una funcionalidad sin evidencia verificable mediante tests o validación definida.
14. El MVP priorizará validar el concepto de aprendizaje interactivo sobre la cantidad de funcionalidades.
15. Toda decisión técnica deberá favorecer mantenibilidad, testabilidad y evolución futura del proyecto.
